# Logger

Лёгкая C++ библиотека для журналирования сообщений в файл
с единым интерфейсом, фильтрацией по уровню важности и потокобезопасной записью.
В комплекте — консольное многопоточное приложение для проверки библиотеки.

---

## Возможности

- **Запись в файл** — журнал хранится в текстовом файле.
- **Три уровня важности** — `Debug`, `Info`, `Error`.
- **Фильтрация** — сообщения ниже заданного уровня не записываются.
- **Смена уровня на лету** — уровень можно менять после инициализации.
- **Метка времени** — каждая запись содержит дату и время.
- **Потокобезопасность** — запись защищена `std::mutex`.
- **Расширяемость** — абстракция `LogTarget` позволяет добавить новые приёмники
- **Без исключений** — ошибки возвращаются через код возврата.
- **Только STL** — никаких сторонних зависимостей (кроме GoogleTest для тестов).
- **Две сборки** — статическая и динамическая библиотека.

> ℹ️ Запись в сокет пока не реализована, но архитектура (`LogTarget`) к этому готова:
> достаточно добавить класс `SocketLogTarget`, реализующий интерфейс.

## Использование приложения
Приложение принимает сообщения из консоли и в отдельном потоке записывает их
в журнал через библиотеку. Передача данных между потоками потокобезопасна.

Запуск

logger_app <файл_журнала> <уровень_по_умолчанию: Debug|Info|Error>

Windows
.\build\Debug\logger_app.exe app.log Info

Linux
./build/logger_app app.log Info
